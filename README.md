# Controlled Style

Melvor Idle Mod on [Mod.io](https://mod.io/g/melvoridle/m/controlled-attack-style)

Adds a Controlled melee attack style: +2 hidden Attack, Strength and Defence levels, XP split evenly between them, and accuracy from the average of your stab, slash and block bonuses. Equipment tooltips show the item's Controlled Attack Bonus.
